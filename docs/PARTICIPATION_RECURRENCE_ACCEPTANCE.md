# Finite occurrence drafts

AI-assisted engineering record. This covers a finite staff workflow within `OS-PART-03`; the broader participation backlog remains open.

## Behavior

Staff choose an ordinary saved Events session or Volunteers shift, inspect its current fields and plan one to eight weekly ordinals at an interval of one to four weeks. The server derives the saved local calendar anchor and time zone. Skips, replacement dates, repeated-time choices and each included title are explicit. Staff review every outgoing field and acknowledge a stored preview before creating the batch.

Creation saves ordinary unapproved drafts and immutable provenance in one transaction. The template stays unchanged. Each occurrence still needs its own ordinary approval and each person's separate participation and consent. This workflow schedules no automatic extension, invitations or delivery.

An uncertain Create retains its original body and command key in page memory. Only deliberate exact Retry sends it again. History describes retained data and current record status; it does not prove acceptance of an unresolved command. Recovery preserves historical fields without restoring accepted-command or live generation authority.

The interface binds unsent count, titles and exceptions to the inspected module and source. Reload removes them from the controls until a fresh matching inspection. A different source starts blank. Derived plan, preview and acknowledgment are never restored as writing.
