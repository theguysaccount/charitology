# Offline attendance for an Events session

Open **Participation**, choose the managed Events session, and select **Load occurrence for attendance**. In **Offline attendance worksheet**, download the worksheet while you have a connection. Open the saved HTML file in a browser at the event. Enter the whole-event totals and save its JSON. Enter 0 if you counted zero. Leave a count blank when it is unknown. The worksheet takes counts only.

When you’re online again, reopen the same session and select the saved JSON. Inspect the counts and confirm they cover the whole event. Review the exact draft before choosing **Create unapproved attendance draft**. If the response is interrupted, choose **Retry exact attendance create**.

The signed worksheet is tied to the approved session and the workspace where it was issued. A changed session needs a fresh review. Keep the original if the app finds a conflict. The same accepted file opens the saved attendance record. An altered copy or another worksheet needs review if the event already has an attendance record, including one in Trash.
