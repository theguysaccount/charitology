## Verification and deliberate capture

From the repository root, use its pinned supported Node version and installed locked dependencies:

```sh

npm run build
npm run check:research-ledger
npm run check:publication-editions

```

The focused check exercises complete source profiles, immutable history, exact-version review invalidation, fictional challenge/response/version correction, deterministic preparation, tamper/stale/orphan/symlink refusal, temporary-directory application and offline Git boundaries. The UI checks render the actual component and exercise its real filter controller in a bounded synthetic DOM. They do not establish native browser layout, file saving or actual human participation.

The [capture interfaces](RESEARCH_LEDGER_INTERFACES.md#additive-encyclopedia-profile) document explicit preparation/application flags. This initial family capture has already been applied; do not replay it to obtain a newer receipt. The current v2 manifest and conflicting IDs must refuse that old operation.

Preparation creates a deterministic candidate and inventory in a fresh ignored cache folder; it does not change the live ledger. Application requires the exact separately reviewed preparation-file SHA, repeats deterministic derivation and committed-source/old-file checks, writes new objects exclusively and installs the mutable manifest last. It restores no review qualification, actor declaration, account grant, delivery or OS authority.

For an interrupted or failed operation, preserve the preparation and inspect the exact inventory. The implementation cleans only matching newly created files on a caught preinstallation failure; changed files require inspection. A process interruption can leave a lock or orphaned output, and subsequent preflight must refuse it. Do not delete an unmatched file or automatically replay after an uncertain result. Compare the full retained state against the prepared bytes before deciding whether installation completed. Actual process-kill/crash recovery is not claimed by the temporary-file refusal tests.
