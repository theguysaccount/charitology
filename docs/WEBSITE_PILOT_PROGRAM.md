# Website improvements and optional Charity OS pilots

Practice draft 0.1 · November 5, 2026 · AI-assisted implementation and official-source review

A charity can start with one website task and inspect a proposed change before choosing what to adopt. The separate OS trial starts with one fictional workflow. Website help does not depend on participation in that trial.

## Public surfaces

- `/for-charities/website-pilots/`: visitor task → source check → private concept → charity decision → review. Includes an editable proposed two-week OS trial, current module links, three sourced community entry routes and separate recurring-update decisions.
- `/for-charities/website-pilots/materials/website-preview-brief.md`: task, current observations, exact version, scope, publication/rights/hosting/rollback decisions and separate update permission.
- `/for-charities/website-pilots/materials/os-pilot-brief.md`: one question, fictional task, responsible roles, unknown baseline, permission/export/recovery checks, midpoint review, stop decision and cleanup.
- Discovery links from the charity hub, collaboration page and networks directory.

The two Markdown documents are complete static UTF-8 downloads, editable without an account. Downloading them creates no record, sends no message and grants no access. Current Projects/Resources links require the ordinary hosted OS sign-in and organization choice. No OS schema, service, mail, provider, payment, account or data-import behavior changes in this release.

## Evidence and authority

These workflows are untested proposals, labeled Hypothesis. No participating team, adoption, completed pilot or increase in donations/charitable outcomes is claimed. The 0–4 depth scale describes mechanisms; every level may be needed. A website review is not a named-charity rating.

Private examples, contact history, replies and consent records stay outside public Git. The charity approves any actual publication and its exact version, scope, rights and maintenance. Recipients choose any recurring updates separately. An initial concept uses original/licensed material and retains official operational routes. Community participation starts with contribution and organizer guidance, not member-contact collection or unsolicited private promotion.
