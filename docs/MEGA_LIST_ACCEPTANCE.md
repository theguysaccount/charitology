# Mega list acceptance audit

Draft engineering audit · initial inspection October 26, 2026; reconciliation October 27, 2026 · AI-assisted source inspection.

Baseline: repository HEAD `c7ffa6aab23fc27cbbc7fd568026964fa3458341`, with a clean working tree when inspection began. This document audits the original **26 programs, 19 tools and 21 information bases** preserved in [ORIGINAL_BRIEF.md](ORIGINAL_BRIEF.md). Charity OS and the two directories are separate additions. The targeted rows below now include explicitly documented follow-up changes; historical counts still describe this baseline. Later work needs its own acceptance evidence.

The site has a working function for every original name. That does **not** mean every original product requirement is complete. A local protocol planner cannot stand in for an executed replication; a bibliography is not a tagged study database; a cause browser without funding observations is not a funding atlas. The existing `live` catalog status describes availability, not this acceptance decision.

## How to read this audit

- **MVP:** an identifiable input → operation → output implements the bounded function. Content coverage, independent review and real-world outcomes remain separate.
- **Partial:** substantive functionality exists, but a specific original workflow or material software requirement is missing.
- **Adapted:** the original requirement has a deliberate replacement under the later framing. This is not evidence that the original feature exists. The replacement may itself be usable.
- **People gate:** an operational milestone needs people, authority, funding, consent or independent review. Software can support it, but cannot declare it satisfied.

These labels are not scores of charities or judgments of the good being done. Every depth is needed. No task below authorizes named-charity ratings, money movement, an invented staffed institution, automatic participant selection or publication of personal records. Missing evidence must stay missing.

Evidence here is code/content inspection, not a new browser test of all 66 items. [IMPLEMENTATION_NOTES.md](IMPLEMENTATION_NOTES.md), [HANDOFF.md](../HANDOFF.md) and [EMAIL_DELIVERY.md](EMAIL_DELIVERY.md) contain earlier test/deployment evidence; historical counts in earlier reports should not be read as current counts. In particular, email **is now configured and publicly enabled**. This audit does not repeat the old claim that email is pending.

Source counts at the baseline: 23 problems, 17 cause areas, 8 framework sketches, 26 encyclopedia entries, 16 organization records, 15 interventions, 13 historical cases, 8 disagreements, 8 traditions, 8 myths, 10 textbook chapters, 3 journal pieces and 5 forecast questions. All five question files have empty forecast arrays. Country data has 217 countries/economies and five indicators. There are six podcast episodes and one letter issue. Small collections are usable starting points, not universal coverage.
