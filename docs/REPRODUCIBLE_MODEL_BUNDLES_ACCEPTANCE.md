# Reproducible model bundles: acceptance record

This records software checks for the Model Kit's new private desk. The examples are fictional. No published source model has been admitted, no estimate has been independently reviewed and no result establishes measured impact. The public registry remains empty. This work was AI-assisted; the source-review requirements in STYLE.md remain open.

## Behavior

The desk retains authored inputs, purpose, population, period, USD cost basis, sources and immutable calculation versions. Draft saving preserves unfinished literal writing. Freezing runs the installed fixed calculation; an amendment appends a version and preserves its predecessor. Copies retain their origin. Source files are not attached; an explicitly chosen file can supply a local byte checksum.

Selected JSON exports one version; a complete private backup retains the library and saved draft. Full outgoing content is reviewed before a download is requested. Inspection, reproduction and copying are separate steps. An imported recorded result is historical until deliberately recalculated here. Reproducing a calculation supplies no independent source review. Unsupported engines remain inert; mismatches and arithmetic refusals permit only an explicitly acknowledged draft copy.

Clear, Restore and guarded Undo require their own complete review. Failed saves retain the reviewed candidate for Retry; newer literal writing stays separate. Foreign saved bytes do not silently replace the editor. All 58 text leaves plus the parser control start disabled and have no default GET names. Only the Model Kit mounts the new desk, outside the original calculator's selector boundary.
