# Completing the 31 seeded and designed items

Date: October 25, 2026 (America/Los_Angeles). AI-assisted implementation, writing and verification. This record concerns software availability and published content, not independently reviewed research or operating institutions.

This is the historical October25 implementation record. See [the current66-item acceptance register](MEGA_LIST_ACCEPTANCE.md) and [handoff](../HANDOFF.md) for later program, email and shared-OS releases.

## Result

All 21 previously seeded and 10 designed original items now have usable browser implementations or substantial published editions. The 66-item roadmap has 57 live functions and 9 institutional programs needing partners. Status means the exact function described on the page; research outcomes, human review, local authorship, professional accreditation and legal funds are separate.

The build produces 444 HTML pages. The original brief remains unchanged. The API now exposes 29 datasets. The two new method papers are explicitly untested proposals, not peer-reviewed research.

## Data and publication evidence

- Country data: 217 nonaggregate World Bank countries/economies, five indicators, 1,050 latest non-empty observations within 2020–2025. Every value retains its year, observation status and footnote. A separate AI-assisted source check re-fetched the exact five API series and metadata: zero stored-value/year/footnote/status differences. Source and producer metadata accompany the UI, API and exports. Locally coauthored narrative profiles are not claimed.
- Podcast: six actual mono MP3 files, 2,133 seconds (about 36 minutes), narrated using the standard macOS Samantha voice. No voice cloning, guest interview or human narration is claimed. Episode pages provide transcripts/source links; RSS contains file sizes and enclosures. All six files fully decoded without audio errors; native-browser playback advanced with no media error.
- Textbook: ten full chapters, searchable index, source-preserving Markdown export, complete reading/print edition and local reading notebooks. Course practice is a different record from a reading marker.
- Journal: manifesto and two substantive proposed-method papers, a bounded manuscript desk with backup/restore and explicit public-PR submission instructions. No independent peer review is claimed.
- Letter: a published first issue plus dedicated newsletter RSS. Email sending is not configured.

- Research model checks: 20 groups; education/planning models: 10 scenario groups; completion models test missing/zero distinctions, integer cents, invalid enums/imports, disclosure requirements, safe spreadsheet text and two-tab overwrite protection.
- Reference checks read the actual built serialization for 8 shelves / 102 records (the failure shelf overlaps historical cases), then execute the actual dossier exporter and check source/review/field retention.
- Actual two-tab browser tests confirmed stale research autosaves and depth-census edits cannot replace newer saved work. The stale page retains an exportable local draft and reload reads the newer version.
- Browser tests cover all 31 targeted routes: filtering/reset/empty states, reading selection, side-by-side intervention fields, local save/edit/delete/undo, import preview/replacement/rejection and reload. Root verified research import through the in-app browser.
- The ten-unit course was completed through visible controls, including wrong-answer explanations, twenty questions, practice, capstone and the shared completion record. Policy and workplace numeric scenarios were checked against independent hand calculations.
- Mobile checks at 390×844 found no horizontal overflow for all 31 targeted pages. Reference and country views retain scrollable comparison tables.
- Strict TypeScript: nine publication inline modules and helpers, all research modules and the learning/planning modules passed.
- Browser print dialogs were reached, but a printed PDF was not visually inspected. Chrome download-event capture was unavailable for reference dossiers; exact generated contents were independently checked, while root in-app-browser book/report/manuscript/research downloads were verified.

## Corrections found during review

- Required numeric planning context no longer becomes zero when missing.
- Nomination Undo cannot erase work saved after a deletion.
- Native-select enums are validated on nomination/manuscript import.
- Local publication drafts, research desks and education/planning workspaces refuse to overwrite newer data from another tab. Corrupt browser data remains untouched.
- Country brief exports preserve uncertainty footnotes and observation status.
- Depth-census CSV text protects whitespace-prefixed formulas. Money totals use integer cents; unclassified money remains separate from depth 0.
- All 217 country state links have real static anchors; internal-link checking remains strict.

## Reproduction

`npm run data:countries` explicitly refreshes the fixed 2020–2025 statistical window from World Bank APIs; ordinary builds use the committed snapshot and need no external data API.

`FFMPEG=/path/to/ffmpeg npm run audio:podcast` regenerates the reading season on macOS using `say`. Ordinary CI uses the committed audio.

## What remains distinct

The 9 partner programs need the funding, legal arrangements, people and governance in their charters. Professional credentials, paid fellowships, real studies, local coauthor approval, human review, store submission/approval and an approved named-charity ranking were not created by this software pass. Email delivery and generative AI are not configured. Existing pinned Astro advisories and .com HTTPS hosting limitations remain documented in HANDOFF.md and the prior release notes.
