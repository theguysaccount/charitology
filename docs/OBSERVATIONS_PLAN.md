A dataset edition pins their exact versions and the complete source closure. Entity aliases are explicit sourced mappings; never fuzzy name/address matches. Financial service geography, beneficiaries, price basis and uncertainty remain unknown unless supported. A mailing state is not service geography.

Every observation retains exact reported token and scale, normalized decimal, actual period variant, unit/denominator, reporting quantum or unknown precision, source status, literal notes and exact source locators. `null`, source absence and numeric zero are distinct. Each missing coverage cell records a reason and references, without pretending a missing point estimate was reported.

No first-release aggregation operation exists. Organization comparison returns aligned facts and explicit compatibility reasons. Different stock dates, fiscal intervals, expense definitions and consolidation boundaries stay visible. Structurally comparable reporting groups can have different scope IDs; requiring identical IDs would make all comparisons impossible. Different identities are never silently harmonized, added, divided or assigned a winner. No FX/inflation conversion, ratio, difference, score, charity rating, cause funding allocation or causal effect is generated.

The current Giving USA recipient rows are not a partition of the headline source-of-giving total. Both official 2026 primary pages match the existing values and explain reconciliation/timing differences. Preserve vintage and these relations. Do not issue a false transcription correction, label a negative residual unallocated giving or fill the Gap Map with derived shares. Existing figures and intervention models are scoped context pending their own source adapters.
