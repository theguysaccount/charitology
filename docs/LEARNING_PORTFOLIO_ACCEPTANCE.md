## Private records and recovery

A new series or amendment requires an exact reviewed input/criteria preview and a fresh unchecked affirmation. An amendment pins its predecessor ID/hash and current head; it cannot rewrite an earlier record or retarget it to another criteria edition. Evaluations are recomputed from retained input. Reading assertions, public correct answers and trimmed text lengths do not assess reasoning or identity. Partial study stays incomplete.

Live capture reads only validated course-store memory, with its saved or unsaved origin disclosed. Dirty DOM strings need a separate deliberate save/apply, or a selected course file. An absent course key is unsaved memory with no raw source hash. An owned, one-use course read lease holds the course lock before the companion lock; final source, memory, saved-text and synchronous UI checks precede the companion-only append. File capture takes only the companion lock. Neither path silently writes course progress or another workspace.

Corrupt/denied initial storage is unavailable, rather than an invented empty course or portfolio. Every mutation/recovery uses the final-key Web Lock, exact observed saved text and a separate memory generation/hash; the companion additionally binds its revision. Quota failure retains a valid memory candidate. Retry persists it once without repeating capture or inventing a date. Plain unfinished-form recovery is separate from a validated backup. Already-open older course tabs need a reload or close; they cannot retroactively gain the new save guard.

Complete portfolio JSON includes every retained record, full criteria and the saved unfinished form, including unselected private work. Selected record JSON/CSV/Markdown contains exactly one immutable record and its complete criteria; predecessor IDs/hashes are provenance only, and omitted ancestors cannot be reconstructed. It is neither a full restore backup nor a submitted credential/fellowship application. Browser-origin storage is accessible to site scripts and people using this browser; it is not encrypted confidential case storage.

## Bounds

- Known-shape legacy course JSON: 400,000 UTF-8 bytes, including pretty formatting/newline. This intentionally expands the old UI's 200,000-byte import ceiling without a format/key migration. The maximum accepted known writer shape is 373,881 bytes. Unknown extras formerly stripped by the old helper are refused and recoverable, not silently discarded.
- At most 20 known immutable criteria artifacts, 262,144 canonical UTF-8 bytes each; at most ten retained study records including amendments. No pruning or truncation.
- Complete pretty portfolio backup, including wrapper, capture instant, checksum and final newline: 2,097,152 bytes. It overrides collection maxima.
- Raw unfinished form: 512 KiB canonical UTF-8, individual strings at most 16,384 UTF-16 code units. Its raw completion-day text remains recoverable even when invalid. When a complete backup cannot hold it, plain recovery remains available.
- Strict JSON depth 32, root container depth one. Decoded duplicate keys, malformed UTF-8, literal unpaired UTF-16 input, accessors, unsupported shapes and unknown fields are refused. JSON-escaped private string values retain their exact code units.

## Recovery correction shared by the earlier local registers

Independent review found a specific corrupt-copy race: protected corrupt A could already block the store, then an unseen valid B could be accepted by the first replacement preview without a new warning. This release applies the corrected baseline rule to the learning stores and existing study, artifact/results and program-graph registers. Each newly observed B or C first blocks replacement and advances only the observed saved-text descriptor; memory remains unchanged and ordinary writes stay blocked. A fresh deliberate preview is required. The protected original A remains separately downloadable, and the recovery UI immediately offers the different last-observed text. A later C invalidates an old B preview.

Actual regression evidence: study store 18 groups / UI 12 controller scenarios; artifact/results store 22 / UI 25; program graph store 25 / UI 30. These totals include existing cases plus new A/B/C and shared helper tests. The new checks preserve both copies, compare unchanged memory and saved text, and verify that refused operations never delete B/C. Corrupt UTF-16 text is JSON-wrapped when Blob text encoding would replace a lone surrogate; its `raw` string retains every original code unit. A wrapped recovery file is not a validated workspace backup. No existing persisted state or backup schema changes.
