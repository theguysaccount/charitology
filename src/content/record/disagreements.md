This register makes disagreements explicit: each entry states the positions it covers, names the *cruxes* that could change minds, and says whether the question is open, narrowing or settled. Readers can add a missing position or challenge the evidence in public.

## Use this reference base

Search the full debate text and references. Filter by debate status, linked system condition or editorial review. Open the recorded fields to read the positions and cruxes together, then select entries to download a source-linked debate dossier.

## Coverage and review

The register does not count positions as votes or decide a debate by how many sources one side cites. Debate status and editorial review are separate fields. Add a missing position or challenge the framing in public.
