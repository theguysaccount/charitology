A field needs a shared vocabulary before it can argue well. The Encyclopedia is that vocabulary at full length: each entry explains one concept, where it came from, what the evidence says and how it connects to the charity system.

Every entry follows [the Charitology Standard](/record/methodology/): plain language, a source for every factual claim, and an honest label where people disagree. Short definitions live in [the Lexicon](/record/lexicon/). Book-length arguments live in [Principles of Charitology](/record/principles/).

## Use this reference base

Search the full entry text, filter by linked system condition or review status, and inspect each source list. Select entries to download a reading dossier that keeps the original text, references and review labels together. Share a filtered view or reading-list link when you want someone else to start from the same material.

## Coverage and review

This is a working collection, not complete coverage of the field. Entries remain drafts until the review standard is met. A source count describes the record; it does not establish the quality of the evidence.
