History is the only laboratory where we can see how giving played out over decades. Each case records what happened, where it sat on the [depth scale](/method/#depth), and the lessons it carries for the system today.

## Use this reference base

Search the full case text and sources, then filter by recorded result, place, depth or review status. Each card exposes the period, setting and lessons stated in its entry. Select cases to download a reading dossier for a workshop, literature review or program discussion.

## Coverage and review

Result labels describe particular cases rather than grading the organizations or people involved. A lesson from one setting needs a fresh argument before it is applied in another.
