Evidence about what did not work can improve later decisions. Charitology’s working hypothesis in [the Silence About Failure](/diagnosis/silence-about-failure/) asks whether the system makes those lessons harder to share. This archive collects documented failures and mixed results, each written as a lesson for the system.

The entries examine published actions and results, without inferring anyone’s motives. Where an organization has responded publicly, its response is included.

## Use this reference base

Filter by recorded result, place, depth or review status. Inspect the original case and its sources before drawing a lesson. Select several cases to assemble a learning dossier that keeps the context and uncertainty attached to each one.

## Coverage and review

The archive reuses documented cases from the historical collection. It is not a complete record of failure, a causal model of every failure or a claim about anyone’s motives. Mixed results remain labeled as mixed.
