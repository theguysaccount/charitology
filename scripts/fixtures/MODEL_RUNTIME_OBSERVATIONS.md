# Model runtime observations, version 1

These files are CI evidence, not engine definitions, replacement goldens, source ratings or calculator exceptions. Browser code, bundle admission, numerical execution and copy authority do not import them.

`model-runtime-observations-v1.json` contains the complete nineteen case DTOs for two measured Node 24.22.1 / V8 13.6.233.17-node.58 profiles:

- Darwin arm64 reproduces the immutable v1 reference fixture exactly.
- Linux x64 has the six complete-array hash differences actually captured by CI on October 28, 2026 at commit `c233fcbb68da9ebc8606407d3406e7b236e7d3c9`. These are the cost and outcome array hashes for ordinary seeds 1, 42 and 4294967295. Every other retained case field is identical. The complete observed golden hash is `323c9e0d6985e11c42589acaa1ca0b3ac7000222c7e5a5a9ff74a639014d6073`.

The Linux DTOs were reconstructed from the unchanged reference fixture and those six captured values. Their complete hash independently closes the actual observed CI hash. They are not regenerated reference values. Qualification computes every case again and compares the whole DTO with this fixed observation. Unknown runtime identities, changed evidence, any new difference and an unexpected result all fail qualification. A matching runtime identity alone never passes it.

The source files, registered definition hash `3826f798e0dc55defdd59cbdfd697a5eef40931f99dd3181abe12c5d8a28f30e`, and reference golden hash `ff19a5fe1b56a0452a225ae801fadeff54d30441683dc705197973943896d527` remain unchanged. `--check` still requires exact reference reproduction. `--check-integrity` checks retained bytes and pins without evaluating arithmetic or claiming numerical conformance.

`model-runtime-macos-arm64-selected-v1.json` is a complete fictional selected bundle generated by the actual production serializer on Darwin arm64 / Node 24.22.1. Its SHA-256 is `c89e562a7a068ea6b8c340f997f1e2eeda632f377dda4d3dce93d02c382fdc5e`. It is a software fixture, not a native browser Save, a real intervention estimate or a publication record. The actual CLI must match it on the measured Mac profile and report precisely the two array fields as mismatched on the measured Linux profile. A newly authored local file must match its own exact local recalculation. A mismatched comparison cannot authorize reproduced copies or draw exports.

No tolerance or rounding is used. Runtime variation is established; the exact contribution of platform exponentiation remains an inference. A portable arithmetic replacement requires a separately reviewed engine version.
